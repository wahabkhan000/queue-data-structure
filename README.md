# Queue Data Structure

A from-scratch implementation of the Queue data structure in C++.

## Concepts Covered
- FIFO (First In, First Out)
- Enqueue
- Dequeue
- Peek
- Empty Queue
- Linked-list implementation
- Dynamic memory management
- Pointer manipulation

## Implementation
Currently implemented:
- Linked-list Queue

## Complexity

| Operation | Time |
|-----------|------|
| Enqueue  | O(1) |
| Dequeue  | O(1) |
| Peek     | O(1) |
| isEmpty  | O(1) |

## Language
C++
